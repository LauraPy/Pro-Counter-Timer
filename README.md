# Pro Countdown Timer 🚀

O aplicație desktop minimalistă de tip cronometru, dezvoltată în Python. Designul este personalizat cu o temă contrastantă roșu-negru și transparență pentru un aspect modern.

## ✨ Caracteristici
- Design Custom: Titlu și cifre încadrate în căsuțe negre.
- Transparență: Fereastra are o opacitate de 90% (alpha 0.9).
- Alarma Audio: Sistemul emite un semnal sonor (Beep) la finalizarea timpului.
- Interfață Flat: Butoane negre fără margini (Flat Design).
